# Emoji catalog

`catalog.json` contains Unicode characters and searchable names, categories,
aliases and tags from GitHub's MIT-licensed Gemoji catalog:
https://github.com/github/gemoji/blob/master/db/emoji.json

Each row is `[emoji, description, category, search terms]`. Emoji are rendered
by the operating system; no image or font assets from Arc are distributed.
See `LICENSE` for the original copyright and license.
