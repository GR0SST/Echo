# Default-browser action in General

General exposes the local default-browser callout when the shared registration interface reports Other. It hides the callout for Ours or Unavailable, refreshes when Settings is opened/reactivated, and disables repeat requests while its operation is pending. The action shares the same global serialization gate and platform boundary as onboarding and the application menu. Declining/cancelling leaves the action available; only the returned OS state can remove it. Errors retain status and use the existing owner toast when available. No tab, renderer, profile assignment or browser-account state changes.

The installed Arc 1.170 executable identifies the callout in `PreferencesFeature/AccountPreferencesViewController.swift`, with the app-name fragment `isn‘t your default browser.`. Arc's General reference when Arc is the default has no such callout. Per the functional-release task, Echo exposes this local action in General while omitting the excluded account pane. The machine's HTTP/HTTPS handlers are Arc; inspecting the positive non-default Arc state would require changing that owner preference. Its exact conditional layout remains unqualified, so ARC_PARITY remains partial rather than claiming a matching non-default visual reference.

Two GPUI checks exercise the actual General button: successful registration removes its row without page replacement; declined registration keeps the row, and activation refreshes an external state change. A retained debug-bounds entry is not treated as a visible control; the checks compare the layout of the surviving Previews row.

Native acceptance uses `BROWSER_TEST_DEFAULT_BROWSER=1`, the existing in-process registration adapter. A real click changes the adapter from Other to Ours; automation records both states, the callout disappears, and the fixture receives one document request. It quits natively. The real OS HTTP/HTTPS handlers remain `company.thebrowser.browser`; no default-browser switch is performed. Inspected evidence: `target/parity/default-browser/before/general-before.png`, `native/general-{before,after}.png`, `native/engine.log`, `native/result.json`, and `native/system-handlers-after.json`. The reference for Arc's default state remains `target/parity/reaudit2/arc_settings_General_Dark.png`.

Windows/Linux registration adapters and non-default visual qualification remain separate acceptance work; the shared General flow does not add platform logic.
