# Retained navigation menus

Arc 1.170's positive reference is a Today page following two ordinary hyperlinks: One → Two → Three. Right-clicking Back shows Two, One; selecting One leaves Forward showing Two, Three; selecting Three returns to the same tab. The painted menu is 220 px wide, with 40 px rows, 8 px vertical padding, a 12 px radius and an arrow over the source button. The two-entry native window includes shadow margins and measures 232×114. This replaces the inventory's unsupported assumption that a Back hold opens the menu: guarded holds through 2.3 seconds, including a settled hover and ordinary link navigation, only navigated Back on release.

Echo queries the retained page's history through CEF's local protocol interface and selects its opaque entry ID. It does not load a copied URL, create a tab, or truncate the Forward stack. Requests are bounded, single-consumer and cancelled on logical close/host transfer; completed or cancelled observers release their native context/runtime leases. Replies and selections are scoped to the original browser/document epoch and the owning window's tab/profile generation. A changed page or profile cannot reuse the old menu. Each painted control captures its own anchor, including a floating sidebar's coordinate system; Split sidebar actions retain the focused pane's scope. Cached favicons belong to the captured local profile. Escape, outside click and selection dismiss the menu; arrow keys and Return select entries.
