# Собственный браузер на Chromium

Этот репозиторий (Rust-приложение, документы, скрипты): https://github.com/GR0SST/browser.
Форк Chromium в `src/` — отдельный репозиторий: https://github.com/GR0SST/chromium

Первичная загрузка исходников выполняется в фоне. Текущее состояние:
`cat .checkout-status` (`downloading`, `ready` или `failed`).
`checkout.log` содержит результат автоматической настройки; `.checkout-revision`
появится после успешного завершения. До `ready` не запускайте sync/build.

`src/` — исходники Chromium. `origin` указывает на личный форк,
`upstream` — на официальный исходный репозиторий Chromium.
Рабочая ветка для изменений браузера: `browser/main`.

Исходники загружаются с последним коммитом main, без полной истории.
При необходимости историю можно получить через `git fetch --unshallow` внутри src.
Это исходная база: собственный интерфейс, название и функции ещё не реализованы.

## Разработка на Mac

```sh
bun run sync       # загрузить зависимости и инструменты из DEPS; длительная операция
bun run build      # GN + компиляция Chromium
bun run browser    # запустить с отдельным локальным профилем
```

`depot_tools/` — официальные инструменты Chromium. PATH настроен только внутри
скриптов; системные настройки оболочки не изменяются. Bun запускает команды,
а сам Chromium собирается штатными GN/Ninja и Python-инструментами.

Настройки разработки: `config/args.gn`. При первой конфигурации они копируются
в `src/out/Default/args.gn`; последующие запуски сохраняют локальные изменения.
Сборка приложения: `src/out/Default/Chromium.app`.

## Где менять браузер

- `src/chrome/browser/ui/` — интерфейс браузера.
- `src/chrome/browser/ui/views/` — панели, вкладки и окна на Views.
- `src/chrome/browser/resources/` — внутренние WebUI страницы.
- `src/chrome/app/` — ресурсы и строки приложения.
- `src/components/` — общие компоненты.
- `src/third_party/blink/` — движок рендеринга; для первых изменений интерфейса его трогать не требуется.

Изменения в `src/` коммитятся и отправляются в личный форк обычным Git.
Вспомогательные файлы рядом с `src/` локальные, в GitHub-форк пока не отправлены.
Перед обновлением Chromium сохраняйте изменения отдельными коммитами;
после выбора новой upstream-ревизии повторяйте `bun run sync`.
Сохраняйте LICENSE и уведомления сторонних компонентов при распространении.
